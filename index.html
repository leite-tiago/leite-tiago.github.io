Featured Architecture Case

TascaEats

A multi-platform food delivery ecosystem engineered across three deliberate evolutionary phases: starting as a clean Spring Boot monolith with RESTful APIs, adding native desktop (JavaFX) and web (Thymeleaf) clients communicating over high-performance gRPC, and transitioning toward containerized microservices with Kafka event streaming and isolated database schemas.

Java Spring Boot PostgreSQL gRPC / Protobuf Apache Kafka JavaFX Thymeleaf Docker
Architectural Evolution
  • Phase 1: Monolithic Spring Boot core with Hibernate JPA and relational PostgreSQL models.
  • Phase 2: Dual-client interfaces (Web & Desktop) integrating bidirectional gRPC streams alongside REST.
  • Phase 3: Event-driven decoupled services orchestrated with Kafka message queues and Docker.

About Me

I hold a Bachelor's degree in Computer Engineering from FCUL (University of Lisbon) and completed the intensive, peer-driven software curriculum at 42 Lisbon.

This dual foundation gave me both sides of the coin: rigorous academic grounding in algorithms, operating systems, and database theory, alongside hundred-hour deep dives building Unix utilities, graphics engines, and distributed network services from scratch in C and C++.

Professionally, I work as a Tech Analyst at Deloitte, applying engineering discipline to enterprise applications. Whether designing a clean REST/gRPC API, establishing transactional integrity in PostgreSQL, or containerizing microservices, my focus is consistently on clarity, resilience, and understanding how the system behaves under the hood.
